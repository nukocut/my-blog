Markdown 的完整语法有一大堆，但日常写作真正用到的其实就那十来个。这篇文章把常用的挑出来，顺便记下几个容易踩的坑。

## 标题

用 `#` 的数量表示层级，`#` 是一级标题。**正文里通常从 `##` 开始**，因为文章标题由 front matter 的 `title` 生成。

```markdown
## 二级标题
### 三级标题
```

## 强调与链接

```markdown
**加粗**、*斜体*、`行内代码`
[链接文字](https://astro.build)
```

渲染出来就是：**加粗**、*斜体*、`行内代码`、[链接文字](https://astro.build)。

## 列表

无序列表用 `-`，有序列表用 `1.`，嵌套时缩进两个空格：

```markdown
- 第一项
  - 嵌套项
- 第二项

1. 第一步
2. 第二步
```

## 代码块

三个反引号开头，后面跟上语言名就能高亮：

````markdown
```js
const greeting = 'hello';
console.log(greeting);
```
````

效果：

```js
const greeting = 'hello';
console.log(greeting);
```

## 引用

```markdown
> 引用的一行
> 可以写多行
```

## 表格

```markdown
| 语法 | 作用 | 常用度 |
| --- | --- | --- |
| `**粗**` | 加粗 | 高 |
| `~~删~~` | 删除线 | 中 |
| `---` | 分割线 | 低 |
```

| 语法 | 作用 | 常用度 |
| --- | --- | --- |
| `**粗**` | 加粗 | 高 |
| `~~删~~` | 删除线 | 中 |
| `---` | 分割线 | 低 |

## 三个容易踩的坑

1. **中文标点没问题，但空格要注意。** 中英文之间留一个空格会好看很多，这是个人习惯，不影响渲染。
2. **代码块里的反引号要成对。** 代码块内部再出现三个反引号时，外层要用四个反引号包起来（上面就是这么做的）。
3. **文件名就是网址。** 这篇文章叫 `markdown-cheatsheet.md`，网址就是 `/blog/markdown-cheatsheet/`。中文文件名也能用，但建议用英文短横线命名。

## 图片

把图片放在 `public/images/` 下（比如 `public/images/cover.jpg`），然后写：

```markdown
![图片说明](/images/cover.jpg)
```

> 注意：如果站点部署在子路径下（比如 `/my-blog/`），图片路径要带上这个前缀，或者改用相对路径。
